The next cell gets the knowledge store ready for fast searching and makes sure every new fact the agent learns lands there too. Search happens in two passes (Figure 3.1): a quick first pass pulls back likely matches, and an optional second pass (reranking) re-reads each one against the question to put the best answer on top. If you see `reranker loaded: False`, the second pass isn't installed in this database; you still get results, just in first-pass order.
