## 3.3 Implement `hybrid_search_knowledge`

Search by meaning misses exact identifiers such as an account number; keyword search misses rephrased text. Combining both covers each gap. Each search returns a ranked list, and a result earns points for its position in each list (Reciprocal Rank Fusion, RRF), with nothing for a list it is missing from. In Figure 3.2, a result found by both searches always beats one found by only one.
