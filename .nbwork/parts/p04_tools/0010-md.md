# Part 4: Toolbox and Skillbox

Guide: [docs/part-4-tools-and-skills.md](docs/part-4-tools-and-skills.md) · TODO 6–8: `retrieve_tools`, `tool_run_sql`, `tool_list_skills`

Tools are the actions the agent can take, such as querying data or saving a note. Skills are written playbooks that tell it how to handle a kind of case. Both are stored in the database so the agent can look them up by meaning. In Figure 4.1, lane A happens once per tool, when it is added. Lane B happens on every turn and shows the agent only the few tools closest to the question.
